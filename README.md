# News-App
I have build a news app by using reactJs.
warning : I use a newapi that not working on online server thats only work on localhost .
So if you want to run this project or app download the code and visit newapi site sign in and get api key .
create a .env file and create a variable VITE_API_KEY="(paste your api key here )" and it will run .
